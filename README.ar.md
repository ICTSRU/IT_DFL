# المكتبة الرقمية للملفات — الإصدار 1.0

خزانة ملفات رقمية للإدارة التنفيذية للاتصالات وتقنية المعلومات: **الخزانة ← الأدراج (المواضيع الرئيسية) ← المجلدات ← الوثائق**.
الملفات في **Google Drive**، والفهرس في **Google Sheet**، والبحث بالعنوان والموضوع والتاريخ والمالك والوسم، والدخول لحسابات **@sr.edu.sa** فقط.

للتجربة بدون إعداد: افتح `index.html?demo=1`.

## خطوات التشغيل

1. **الخلفية:** أنشئ Google Sheet جديدًا ← Extensions ← Apps Script ← الصق `apps-script/Code.gs` و`appsscript.json` ← شغّل الدالة `setup` مرة واحدة (تنشئ الأوراق والأدراج ومجلدات Drive وتضيفك مديرًا).
2. **تسجيل الدخول:** في Google Cloud Console أنشئ OAuth Client ID (نوع Web application، شاشة الموافقة Internal)، وأضف أصل GitHub Pages مثل `https://ictsru.github.io` ضمن Authorized JavaScript origins. الصق المعرّف في ورقة **Config** (الصف ClientID) وفي `assets/js/config.js` (GOOGLE_CLIENT_ID).
3. **النشر:** Deploy ← New deployment ← Web app: التنفيذ باسمك (Me)، والوصول Anyone. انسخ الرابط (ينتهي بـ `/exec`) إلى `WEB_APP_URL`.
4. **المستخدمون:** أضفهم في ورقة **AllowedUsers** بدور Admin أو Editor أو Viewer.
5. **GitHub:** ارفع محتويات المجلد، أضف الشعارات في `assets/img/`، ثم فعّل GitHub Pages (main / root).

## الأدوار

| الدور | الصلاحيات |
|---|---|
| Admin (مدير) | كل شيء: الأدراج والمجلدات وأي وثيقة |
| Editor (محرر) | إضافة مجلدات ووثائق، وتعديل/حذف ما أنشأه أو يملكه، ويرى الوثائق السرية |
| Viewer (قارئ) | تصفح وبحث وفتح، ولا يرى الوثائق السرية |

## ملاحظات

- عند فتح وثيقة يمنحك الخادم صلاحية عرض ذلك الملف فقط (دون إرسال بريد) ويسجّل العملية؛ لا تُشارك الملفات علنًا ولا بالرابط.
- ورقة **AccessLog** تسجّل كل دخول (البريد، التاريخ، الوقت) وكذلك الفتح والإضافة والتعديل والحذف ومحاولات الرفض.
- الحذف «ناعم»: يبقى السطر في الورقة والملف في Drive.
- للتفاصيل الكاملة (بالإنجليزية) راجع `README.md`.
